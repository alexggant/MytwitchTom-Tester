# MytwitchTom

A Chrome extension of small upgrades for watching Twitch: player controls, emotes, chat, watch streaks, VOD markers and split screen.

## Install (about 1 minute)

1. Go to **[Releases](../../releases/latest)** and download `MytwitchTom-2.0.zip`.
2. Unzip it. You get a folder called `MytwitchTom`. Put it somewhere it can stay, like Documents; Chrome loads the extension from that folder every time.
3. In Chrome, go to `chrome://extensions`.
4. Turn on **Developer mode** (switch in the top-right corner).
5. Click **Load unpacked** and choose the `MytwitchTom` folder.
6. Open or refresh any twitch.tv tab.

To update: replace the folder with the new one, click the reload arrow on MytwitchTom's card in `chrome://extensions`, and refresh Twitch.

The release also has **MytwitchTom-2.0-Guide.pdf**, which shows what every feature does.

## Features

- **Player:** click the video to pause/play; a button showing the current volume that drops it to 1% when clicked; bigger slider and playhead; VOD time labels raised above markers.
- **Emotes and chat:** quick phrases (saved messages, emotes included); pinned emotes and Frequent Channels in the emote picker.
- **Watch streaks:** a streak flame with a tooltip; Auto Saver / Streak Saver / Off to keep streaks alive.
- **Channel points:** reward search; the Claim Bonus button is clicked for you.
- **People:** right-click a chatter for notes, pronouns and where you know them from; an account switcher in the avatar menu.
- **Split screen:** watch two streams side by side, each with its own chat, with a sound menu to pick which one you hear.
- **VODs:** markers with notes, live bookmarks that carry over, and a marker list.

Everything is stored in your own Chrome; nothing is sent anywhere except Twitch.
